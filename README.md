# codex-web-cli

Node.js CLI wrapper for opening Codex Cloud and handling repo handoff tasks.

## Install

```bash
npm install -g .
```

## Cloud commands

- `codex-web open` — open `https://chatgpt.com/codex/cloud`
- `codex-web cloud` — alias of `open`

## Repo helper commands

- `codex-web status`
- `codex-web repo`
- `codex-web pr`
- `codex-web handoff`
